# StudioBinder × Creative Developer — Persian Handbook

یک سایت استاتیک RTL برای مطالعه موضوعات کانال StudioBinder از منظر Creative Development.

- **22 مجموعه** و **142 درس تألیفی**؛ درس‌ها فهرست دقیق ویدیوهای رسمی نیستند.
- جستجوی سراسری و فیلتر موضوعی؛ ذخیره علاقه‌مندی‌ها در LocalStorage.
- مثال‌های کدنویسی مستقل، توضیح هدف، کاربرد، تفاوت فناوری‌ها و تمرین.
- دموی CSS داخلی و آزمایشگاه WebGL با Three.js / GSAP.
- فونت آپلودشده توسط صاحب پروژه برای جلوگیری از فایل فونت جداگانه در CSS تعبیه شده است. پیش از انتشار عمومی از مجوز بازنشر فونت مطمئن شوید.

## GitHub Pages

انتشار به‌صورت خودکار با GitHub Actions انجام می‌شود (`.github/workflows/deploy.yml`).

- هر `push` روی شاخه `main` سایت را دوباره منتشر می‌کند؛ اجرای دستی هم از **Actions → Deploy to GitHub Pages → Run workflow** ممکن است.
- تنظیم ریپو: **Settings → Pages → Source = GitHub Actions**.
- آدرس سایت: https://devamir99.github.io/studiobinder-shortlist-all-playlist/
